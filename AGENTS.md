# Coding handover

Read README.md and docs/NEXT-AGENT.md first. This repository is a standalone Moonshiner Marketing Hub export. Use existing Laravel services and tests. Provider dispatch is implemented in Services/Connector; see docs/AGENTS-INTEGRATION.md. Do not confuse this host connector with the separate disabled HTTP agent APIs. Preserve human approval, version hashes and idempotency. Keep credentials out of code, prompts, logs and public issues. Test with isolated data. Update docs and the in-app TechnicalHandover page when behavior changes. No automatic publishing or production migrations during local development.
